# 심사용 화면 녹화 지침 (Guideline 2.1 항목 1)

Apple이 요구한 6개 항목 중 **1번(실기기 화면 녹화)만 사람이 해야 한다.**
2~6번은 `resolution_reply_en.txt` 에 적혀 있고 ASC 심사 메모에도 올라가 있다.

## 준비

1. **TestFlight로 앱을 받는다**
   - `officer75@nate.com` 메일에서 TestFlight 초대를 수락한다
   - App Store에서 TestFlight 앱을 설치한 뒤 「매일매일 수학」을 설치
   - 내부 테스트 그룹 「내부 테스트」에 이미 등록돼 있다

2. **녹화 전에 앱을 삭제하고 다시 설치한다**
   - Apple은 "must begin with launching the app" 을 요구한다
   - 첫 실행(별명 설정)부터 보여야 하므로, 이미 쓰던 상태면 삭제 후 재설치

3. **화면 기록 켜기**
   - 설정 > 제어 센터 > 「화면 기록」 추가
   - 제어 센터에서 녹화 시작. 마이크는 꺼도 된다

## 녹화 순서 (약 3~4분)

각 화면에서 **2초 정도 멈춰** 리뷰어가 읽을 시간을 준다.

| # | 보여줄 것 | 확인 포인트 |
|---|---|---|
| 1 | 홈 화면에서 앱 실행 (아이콘 탭) | 실행부터 시작해야 한다 |
| 2 | 별명 입력 → 학년 선택 | 로그인·회원가입이 **없다**는 것이 드러난다 |
| 3 | 홈 화면 | 시작 버튼, 오늘의 도전, 목표 진행률 |
| 4 | 게임 1판을 **끝까지** 푼다 (20문제) | 중간에 끊지 말 것. 정답·오답 둘 다 섞어 넣는다 |
| 5 | 결과 화면 | 점수, 등급, 최대 콤보 |
| 6 | 홈 하단 **리더보드** 버튼 | 학년 필터도 한 번 눌러 본다 |
| 7 | **남의 기록을 길게 누른다**(약 1초) → **신고하기 / 안 보이게 하기** 메뉴 | **가장 중요.** UGC 안전장치가 여기서 보인다. 내 기록에는 메뉴가 안 나온다 |
| 8 | **안 보이게 하기**를 실제로 눌러 그 행이 사라지는 것까지 | 차단이 즉시 적용되는 것을 보여준다 |
| 9 | **우측 상단 사람 아이콘** → 프로필 | 업적, 스트릭, 데이터 초기화 버튼 |
| 10 | 부모 대시보드 진입 — 게이트 통과 | 한글 곱셈 문제를 푸는 장면. 리뷰어가 막히는 지점이다 |
| 11 | 부모 대시보드 **두 탭**(학습 현황 / 목표 설정) | 연산별 정답률 표가 보여야 한다 |
| 12 | 홈으로 돌아가 **가족 리더보드** 버튼 | 부모 대시보드 탭이 아니라 홈의 별도 버튼이다 |

## 넣지 않아도 되는 것

- **계정 삭제 흐름** — 계정 생성이 없으므로 요구 대상이 아니다
- **유료 콘텐츠** — 인앱결제가 없다

## 7번을 반드시 넣어야 하는 이유

Apple이 요구한 항목에 "any user-generated content, including the required
content reporting and blocking mechanisms" 가 있다. 이 앱의 UGC는 리더보드
별명이고, 신고·차단은 **행을 길게 눌러야** 나온다. 리뷰어가 스스로 찾지
못하면 가이드라인 1.2 위반으로 다시 반려될 수 있다.

메뉴 항목 이름이 「신고」·「차단」이 아니라 **「신고하기」·「안 보이게 하기」**
라는 점도 중요하다. 심사 메모에 짧은 쪽으로 적었다가 실제 화면과 어긋나는 것을
발견해 고쳤다 — 리뷰어는 한국어를 못 읽고 **글자를 맞춰** 찾는다.

## 제출

1. 녹화 파일을 ASC > 앱 심사 정보 > 첨부 파일에 올린다
   (또는 Resolution Center 답변에 첨부)
2. `resolution_reply_en.txt` 전문을 Resolution Center 답변란에 붙여넣는다
3. 심사 메모는 이미 갱신돼 있다 — 다시 입력할 필요 없다
