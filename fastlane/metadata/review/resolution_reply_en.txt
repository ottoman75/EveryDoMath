2. PURPOSE AND TARGET AUDIENCE
--------------------------------------------------------------------------
EveryDoMath is a mental-arithmetic drill app for elementary school children in
grades 1 through 6, and for the parents who practice with them.

One session is 20 problems, generated on the device, scoped to the child's
grade:
  Grade 1  addition and subtraction within 20
  Grade 2  addition and subtraction within 100
  Grade 3  addition, subtraction, multiplication (1-9 times tables)
  Grade 4  the four operations; 2-digit x 1-digit, division without remainder
  Grade 5  fraction addition and subtraction, decimal addition and subtraction
  Grade 6  fraction multiplication and division, decimal multiplication and
           division

The problem it solves: daily arithmetic practice is repetitive for the child and
invisible to the parent, who cannot tell which operation the child is actually
weak at. The value it provides: a session takes about two minutes, the child
gets immediate per-problem feedback plus a score and grade, and the parent can
open the Parent Dashboard to see accuracy broken down by operation along with
the current practice streak. All six grades are free. There is no advertising,
no in-app purchase and no subscription.

3. SETUP AND ACCESS INSTRUCTIONS
--------------------------------------------------------------------------
No login credentials or sample files are required. There is nothing to register
and no demo account, because the app has no account system. On first launch it
signs in to Firebase Anonymous Authentication in the background; the child only
types a nickname (2-12 characters) and picks a grade. Since no account can be
created, there is no account deletion flow to demonstrate.

Data removal is still available: Profile > "데이터 초기화" (Reset Data) erases
all local records and also deletes the user's public leaderboard entry and
family-group membership on the server.

How to reach each feature:
  Home         The large start button begins a session. The Daily Challenge
               card and the daily goal progress bar are on the same screen.
  Game         20 problems, on-screen number pad, per-problem timer ring.
  Result       Score, grade (S/A/B/C/D), max combo, and a shareable card.
  Leaderboard  Home > 랭킹. Global top 50, filterable by grade.
               To report or hide an entry, LONG-PRESS any row that is not your
               own. A context menu appears with 신고 (report) and 차단 (hide).
  Profile      Home > 프로필. Achievements, streak, and Reset Data.
  Parent area  Home > 부모 대시보드, behind a parent gate (see below). Tabs:
               dashboard (accuracy per operation), 목표 설정 (daily goal and
               study reminder), 가족 랭킹 (family group joined by a
               6-character invite code).

PARENT GATE — please read before testing:
The Parent Dashboard is behind a gate showing a two-digit multiplication written
in Korean words, for example "십사 곱하기 십칠". Both numbers are between 11 and
19. The Korean number words are: 십일=11, 십이=12, 십삼=13, 십사=14, 십오=15,
십육=16, 십칠=17, 십팔=18, 십구=19.
So "십사 곱하기 십칠" means 14 x 17 = 238. Type the product and tap 확인. A
wrong answer simply generates a new question. The gate is deliberately harder
than the app's own content, and written in words rather than digits, so that a
child using the app cannot pass it by doing the arithmetic.

4. EXTERNAL SERVICES, TOOLS AND PLATFORMS
--------------------------------------------------------------------------
Exactly two services, both from Firebase (Google):

  - Firebase Anonymous Authentication
    Issues an anonymous user id so the server can verify who is writing a
    leaderboard record. No email address, phone number, or social login is
    involved, and no personal identifier is requested from the user.

  - Cloud Firestore
    Stores the public leaderboard entry (nickname, grade, score, correct
    count), family-group membership, and nickname reports.

The linked Firebase libraries are exactly FirebaseCore, FirebaseAuth and
FirebaseFirestore. There is no analytics SDK, no crash reporter, no advertising
SDK, no payment processor, no AI or machine-learning service, and no
third-party data provider of any kind.

All math problems are produced by on-device code, so solving problems works
fully offline. Only the leaderboard and the family group require a network
connection.

ADDITIONAL CONTEXT — USER-GENERATED CONTENT (GUIDELINE 1.2)
--------------------------------------------------------------------------
Nicknames chosen by users appear on the public leaderboard, so the app includes:
  - Filtering: nickname validation blocks banned words and strings that look
    like personal information (4 or more consecutive digits). The nickname
    screen warns users not to enter real names, school names or phone numbers.
  - Reporting: any leaderboard entry can be reported (신고) as described in
    item 3.
  - Blocking: any leaderboard entry can be hidden (차단) from the same menu,
    which takes effect immediately.
  - Server-side rules prevent a user from reporting themselves, impersonating
    another reporter, or reading the reports collection.
