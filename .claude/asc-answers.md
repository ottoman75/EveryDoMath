# App Store Connect 웹 UI 응답표

API로 처리할 수 없어 사람이 클릭해야 하는 항목이다. **답은 전부 아래에 있다.**
근거는 실제 코드에서 확인한 것이며, 추측이 아니다.

## 1. 연령 등급 설문

**모든 콘텐츠 항목 = `없음`.** 이 앱은 초등 수학 문제 풀이만 한다.

| 항목 | 답 |
|---|---|
| 폭력(만화/판타지/사실적) | 없음 |
| 성적 콘텐츠·노출 | 없음 |
| 욕설·저속한 유머 | 없음 |
| 알코올·담배·약물 | 없음 |
| 공포·무서운 테마 | 없음 |
| 도박(시뮬레이션 포함) | 없음 |
| 의료·치료 정보 | 없음 |
| 콘테스트 | 없음 |
| 제한 없는 웹 접근 | **아니요** (앱에 웹뷰·외부 링크 없음) |

**사용자 생성 콘텐츠 / 소셜 기능을 묻는 항목이 있으면 `예`.**
리더보드에 사용자가 지은 별명이 다른 사용자에게 표시된다. 숨기지 말 것 —
심사자가 리더보드를 보면 바로 드러나고, 숨긴 것이 더 큰 문제가 된다.
필터·신고·차단이 구현돼 있어 가이드라인 1.2는 충족한다.

→ 결과 등급: **4+** (UGC 항목 때문에 상향될 수 있으며, 그대로 수용한다)

> **Kids Category에는 옵트인하지 않는다.** 외부 링크 부모 게이트 등
> 별도 요구사항이 붙어 리젝 위험만 커진다. 4+ 등급과 교육 카테고리로 충분하다.

## 2. 앱 개인정보 (영양성분표)

앱의 `PrivacyInfo.xcprivacy` 와 **반드시 일치해야 한다.** 불일치는 리젝 사유다.

### 수집하는 데이터

| 데이터 유형 | 분류 | 연결됨 | 추적 | 목적 |
|---|---|---|---|---|
| **식별자 → 사용자 ID** | Firebase 익명 인증 uid | 예 | 아니요 | 앱 기능 |
| **사용자 콘텐츠 → 기타 사용자 콘텐츠** | 사용자가 지은 별명 | 예 | 아니요 | 앱 기능 |

### 수집하지 않는 것 (전부 `아니요`)

연락처 정보 · 이름 · 이메일 · 전화번호 · 주소 · 위치 · 건강/피트니스 ·
금융 정보 · 사진/비디오 · 오디오 · 연락처 · 검색 기록 · 탐색 기록 ·
구매 내역 · 진단 · 사용 데이터 · 광고 데이터

**"데이터를 추적 목적으로 사용합니까?" → 아니요.**
광고 SDK도 애널리틱스도 없다 (`IS_ANALYTICS_ENABLED = False`).

> 게임 점수·학년·업적은 기기(UserDefaults)와 Firestore에 저장되지만, Apple의
> 데이터 유형 분류에는 해당 항목이 없다. 별명과 함께 묶여 올라가므로
> "기타 사용자 콘텐츠"에 포함해 신고한 것이다.

## 3. 카테고리 (API 로 설정 가능 — 6단계에서 자동 처리)

- **주 카테고리: 교육**
- 부 카테고리: 비워두거나 `게임 > 교육용`

주 카테고리를 `게임`으로 하면 게임 관련 심사 항목이 추가된다. 교육이 안전하다.

## 4. 심사 메모 (App Review Information)

심사자가 리더보드의 UGC를 보고 가이드라인 1.2를 물을 수 있다. 미리 적어 둔다.

```
이 앱은 리더보드에 사용자가 직접 지은 별명을 표시합니다.
가이드라인 1.2 요구사항을 다음과 같이 충족합니다.

1. 콘텐츠 필터: NicknameValidator 가 별명 입력 시점에 길이(2~12자),
   연속 숫자 4자리 이상(전화번호·생년월일), 금칙어를 차단합니다.
   공백·특수문자를 제거한 뒤 비교하므로 우회 입력도 걸러집니다.
2. 신고: 리더보드 행을 길게 누르면 '신고하기' 가 나오며,
   신고 내용은 Firestore reports 컬렉션에 기록되어 운영자가 검토합니다.
3. 차단: 같은 메뉴의 '안 보이게 하기' 로 해당 사용자를 즉시 숨길 수 있으며,
   신고 시 자동으로 함께 숨겨집니다.
4. 연락처: 지원 URL(https://ottoman75.github.io/everydomath-privacy/support.html)로 문의를 받습니다.

별명 입력 화면에는 '실명·학교·전화번호는 쓰지 마세요' 안내를 상시 노출합니다.
로그인이 없으며, 사용자 식별자는 Firebase 익명 인증 uid 입니다.
실명·이메일·전화번호·위치를 수집하지 않습니다.
```

**데모 계정은 불필요하다** (로그인 없음). 해당 항목은 비워 둔다.
