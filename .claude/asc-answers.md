# App Store Connect 웹 UI 응답표

ASC API 가 지원하지 않아 사람이 클릭해야 하는 항목이다.
**매일매일 수학** 기준으로 채워져 있다. 다른 앱이면 「판단 기준」을 읽고 고쳐 쓴다.

> 연령 등급 설문은 **2026년 9월 기준 7단계 마법사**다. Apple 이 개편하면 구조가
> 바뀐다. 화면과 다르면 **화면을 믿고 이 파일을 갱신**할 것.

---

## 연령 등급 — 7단계

등급은 **실시간 재계산**된다. 확신이 서지 않는 항목은 값을 바꿔 보고 7단계의
「계산된 등급」이 어떻게 변하는지 확인한 뒤 정한다.

### 1단계: 특징

앱 내 제어 기능과 제공 기능을 묻는다. 전부 `아니요`/`예` 2지선다.

| 항목 | 답 | 판단 기준 |
|---|---|---|
| 유해 콘텐츠 차단 | **아니요** | 부모가 콘텐츠를 모니터링·제한하는 설정이 있는가. 부모 대시보드가 **학습 관리**용이면 해당 없음. 부모 게이트·PIN 이 있어야 `예` |
| 나이 확인 | **아니요** | 생년월일 입력이나 연령 확인 메커니즘이 있는가. 학년 선택은 연령 확인이 아니다 |
| 제한되지 않은 웹 액세스 | **아니요** | `WKWebView`·`SFSafariViewController`·외부 링크가 있는가 |
| **사용자 생성 콘텐츠** | **예** | 사용자가 만든 것(별명·글·이미지)이 **다른 사용자에게 보이는가**. 리더보드에 별명이 뜨면 `예` |
| **소셜 미디어** | **아니요** | 아래 주의 참조 |
| 13세 미만 사용자의 소셜 미디어 비활성화 | **아니요** | 소셜 미디어가 `아니요` 면 해당 없음 |

> ⚠️ **「소셜 미디어」를 `예`로 하면 안 되는 이유**
>
> 정의는 *"소셜 피드 또는 유사한 발견 방법을 통해 UGC 를 재배포·확산하거나
> 상호작용하여 많은 사용자에게 퍼뜨린다"* 이다. **피드·팔로우·댓글·재게시·DM**
> 이 없으면 아니다. 순위 목록은 소셜 미디어가 아니다.
>
> `예` 로 하면 바로 아래 **"13세 미만 소셜 미디어 비활성화"** 요구가 붙고,
> 이는 **Declared Age Range API 구현**을 전제한다. 구현이 없는데 `예` 라고 하면
> 거짓 신고다. 등급도 크게 올라간다.

> **UGC 를 `예` 로 해도 등급이 13+ 가 되지는 않는다.** (실측 확인)
> 정직하게 신고하고 4+ 를 받을 수 있다. 숨길 이유가 없다.

### 2단계: 성적 테마

화면 제목은 "성적 테마" 인데 **실제 항목은 욕설·공포·약물**이다. Apple 의 분류
표기가 어긋나 있으니 제목이 아니라 항목을 보고 답한다. `없음`/`드문`/`빈번`.

| 항목 | 답 |
|---|---|
| 욕설 또는 노골적인 유머 | **없음** |
| 잔혹/공포 테마 | **없음** |
| 음주·흡연·약물 사용 | **없음** |

> UGC 가 있어도 **앱이 의도적으로 제시하는 콘텐츠가 아니면 `없음`** 이다.
> 입력 필터 + 신고·차단이 있고 UGC 를 1단계에서 신고했다면 과잉 신고할 필요 없다.
> 화면이 잘릴 수 있으니 **스크롤해서 항목이 더 있는지 확인**할 것.

### 3단계: 의료 또는 건강

| 항목 | 답 | 판단 기준 |
|---|---|---|
| 의료 또는 치료 정보 | **없음** | 건강 상태 진단·지침을 제공하는가 |
| 건강 또는 웰빙 주제 | **아니요** | 아래 주의 참조 |

> 「건강 또는 웰빙 주제」 = *"자기 관리 또는 추천 생활 습관"*.
> **의료·건강 섹션에 속하므로 수면·운동·식단 같은 건강 습관을 뜻한다.**
> 학습 목표·스트릭·리마인더는 **학습 습관**이지 건강 습관이 아니다 → `아니요`.

### 4단계: 성적인 내용 또는 노출

| 항목 | 답 |
|---|---|
| 성적이거나 선정적인 테마 | **없음** |
| 성적인 내용 또는 노출 | **없음** |
| 노골적인 성적 내용 및 노출 | **없음** |

### 5단계: 폭력

| 항목 | 답 |
|---|---|
| 만화 또는 비현실적인 폭력 | **없음** |
| 적나라한 폭력 | **없음** |
| 잇따른 폭력의 생생한 묘사 / 가학적 사실적 폭력 | **없음** |
| 총 또는 기타 무기 | **없음** |

> 번개·불꽃 같은 SF Symbols 아이콘을 UI 장식으로 써도 무기·폭력 묘사가 아니다.

### 6단계: 우연에 기반한 활동 ← **가장 중요**

**기본값이 비어 있다.** 네 항목 모두 직접 클릭해야 넘어간다.

| 항목 | 답 | 판단 기준 |
|---|---|---|
| 가상 도박 | **없음** | 현금 교환이 안 되는 머니로 베팅하는가 |
| **시합** | **드문** | 아래 주의 참조 |
| 도박 | **아니요** | 현금(교환 가능 포함)으로 베팅하는가 |
| 랜덤 박스 | **아니요** | 구입 가능한 무작위 아이템 상자가 있는가. IAP 가 없으면 해당 없음 |

> 🔴 **「시합」 빈도가 연령 등급을 가른다.** 이번 앱에서 실측했다.
>
> | 시합 | 결과 등급 |
> |---|---|
> | 빈번 | **13+** |
> | 드문 | **4+** |
>
> 정의는 *"사용자가 순위·보상·개인 목표 달성을 위해 **서로 경쟁**할 수 있는 이벤트"* 다.
> 핵심 조건은 **"서로 경쟁"** 이다.
>
> **`없음` 은 안 된다.** 리더보드가 있으면 거짓이고, 심사자가 버튼 한 번에 확인한다.
>
> **`드문` 과 `빈번` 은 실제 사용 흐름으로 판단한다.**
> - 주 활동이 **혼자 하는 것**이고 리더보드는 **별도 화면으로 들어가야** 보이면 → `드문`
> - 경쟁이 핵심 루프에 있고 매 화면에 노출되면 → `빈번`
>
> 개인 목표(오늘의 도전 등)는 타인과의 경쟁이 아니므로 빈도 판단에서 제외한다.

### 7단계: 추가 정보

| 항목 | 값 |
|---|---|
| 계산된 등급 | **4+** 확인 |
| 연령 카테고리 및 재정의 | **해당 없음** |
| 연령 적합성 URL | 비워둠 (선택) |

> 🔴 **「어린이용」(Kids Category)에 옵트인하지 않는다.**
> 4+ 가 되면 이 선택지가 나타나는데, 이름만 보면 맞아 보이지만 별도 요구사항이 붙는다.
>
> 결정적으로 **개인 식별 정보나 기기 정보를 제3자에게 전송할 수 없다.**
> Firebase 등 외부 백엔드로 사용자 데이터를 보내면 위반 소지가 크다.
> 외부 링크·구매에 부모 게이트도 요구된다.
>
> **4+ 등급만으로 대상 연령층 노출에는 충분하다.**

> 일부 국가(모로코·아프가니스탄 등) 판매 제외 경고가 뜰 수 있다. 등급과 무관한
> 별도 규정이며 대응할 것이 없다.

## 앱 개인정보 (영양성분표)

앱의 `PrivacyInfo.xcprivacy` 와 **반드시 일치해야 한다.** 불일치는 리젝 사유다.

### 수집하는 데이터

| 데이터 유형 | 실제 값 | 연결됨 | 추적 | 목적 |
|---|---|---|---|---|
| 식별자 → **사용자 ID** | 익명 인증 uid | 예 | 아니요 | 앱 기능 |
| 사용자 콘텐츠 → **기타 사용자 콘텐츠** | 사용자가 지은 별명 | 예 | 아니요 | 앱 기능 |

### 수집하지 않는 것 (전부 `아니요`)

연락처 정보 · 이름 · 이메일 · 전화번호 · 주소 · 위치 · 건강/피트니스 ·
금융 정보 · 사진/비디오 · 오디오 · 연락처 · 검색 기록 · 탐색 기록 ·
구매 내역 · 진단 · 사용 데이터 · 광고 데이터

**"데이터를 추적 목적으로 사용합니까?" → 아니요.**

> 게임 점수·학년·업적은 기기와 서버에 저장되지만 Apple 의 데이터 유형 분류에
> 해당 항목이 없다. 별명과 묶여 올라가므로 "기타 사용자 콘텐츠" 에 포함해 신고한다.

## 심사 메모 (App Review Information)

UGC 가 있으면 심사자가 가이드라인 1.2 를 물을 수 있다. 미리 적어 둔다.

```
이 앱은 리더보드에 사용자가 직접 지은 별명을 표시합니다.
가이드라인 1.2 요구사항을 다음과 같이 충족합니다.

1. 콘텐츠 필터: NicknameValidator 가 별명 입력 시점에 길이(2~12자),
   연속 숫자 4자리 이상(전화번호·생년월일), 금칙어를 차단합니다.
   공백·특수문자를 제거한 뒤 비교하므로 우회 입력도 걸러집니다.
2. 신고: 리더보드 행을 길게 누르면 '신고하기' 가 나오며,
   신고 내용은 Firestore reports 컬렉션에 기록되어 운영자가 검토합니다.
3. 차단: 같은 메뉴의 '안 보이게 하기' 로 해당 사용자를 즉시 숨길 수 있으며,
   신고 시 자동으로 함께 숨겨집니다.
4. 연락처: 지원 URL(https://ottoman75.github.io/everydomath-privacy/support.html)로 문의를 받습니다.

별명 입력 화면에는 '실명·학교·전화번호는 쓰지 마세요' 안내를 상시 노출합니다.
로그인이 없으며, 사용자 식별자는 Firebase 익명 인증 uid 입니다.
실명·이메일·전화번호·위치를 수집하지 않습니다.
```

**데모 계정은 불필요하다** (로그인 없음). 해당 항목은 비워 둔다.

## 체크리스트

- [ ] 1단계 — UGC `예`, 소셜 미디어 `아니요`
- [ ] 2~5단계 — 전부 `없음`/`아니요` (스크롤해서 누락 확인)
- [ ] 6단계 — **네 항목 모두 클릭**, 시합은 `드문`
- [ ] 7단계 — 등급 **4+** 확인, 재정의 `해당 없음`, **어린이용 선택 안 함**
- [ ] 앱 개인정보 — `PrivacyInfo.xcprivacy` 와 일치
- [ ] 심사 메모 붙여넣기
